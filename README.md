# Signal Noise & Filtering Simulator

A web-based simulator that demonstrates how artificial noise affects a signal and how digital filters can reduce it.

## About the Project

The Signal Noise & Filtering Simulator generates a clean sine wave, adds artificial random noise, and applies digital filtering techniques to reduce the noise.

The simulator displays the original, noisy, and filtered signals through graphical representations. It also calculates the Signal-to-Noise Ratio (SNR) before and after filtering to compare signal quality.

## Features

- Sine wave signal generation
- Adjustable signal frequency and amplitude
- Adjustable sampling rate and signal duration
- Artificial random noise generation
- Moving Average Filter
- Median Filter
- Adjustable filter window
- Graphical comparison of original, noisy, and filtered signals
- SNR calculation before and after filtering
- Interactive user controls

## Filtering Techniques

**1. Moving Average Filter**

Reduces noise by calculating the average of neighbouring sample values.

**2. Median Filter**

Reduces sudden noise spikes by selecting the middle value of neighbouring sample values.
